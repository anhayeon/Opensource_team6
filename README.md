## 4. Dependencies

Requires Python 3.10 or newer. The packages below are installed automatically by pip.

| Package | Import name | Version | License | Used for |
|---|---|---|---|---|
| [NumPy](https://pypi.org/project/numpy/) | `numpy` | >=1.26 | BSD-3-Clause | Pixel arrays and color-space math |
| [Pillow](https://pypi.org/project/Pillow/) | `PIL` | >=10 | MIT-CMU | Reading and saving JPG / PNG files |

Standard library modules are not listed.
All dependencies use permissive licenses compatible with this project's MIT license.
