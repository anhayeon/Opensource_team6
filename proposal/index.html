    프로젝트 제안서: "SeeAllColors"

    1. 프로젝트 주제

    만들고 싶은 프로그램

    사용자가 선택한 색각 이상 종류(적색맹, 녹색맹, 청색맹)에 맞춰 입력 사진의 색을 보정하여, 해당 사용자가 원본의 색 구분 정보를 최대한 유지한 채 볼 수 있도록 만든 새 이미지를 저장하는 Python 패키지를 개발.

    사용자 정의 및 해결할 문제

    색각 이상이 있는 사용자는 사진, 차트, 포스터 등에서 서로 다른 색이 비슷하게 보여 정보를 놓치는 문제를 겪음. 이 프로그램은 구분하기 어려운 색 차이를 해당 유형이 잘 인식하는 색 영역으로 옮겨, 사진 속 색 정보를 구분할 수 있도록 도와줌.

    2. 개발할 기능

    입력

    사용자가 컴퓨터에 저장한 이미지 파일(JPG,PNG) 색각 이상 종류: 적색맹,녹색맹,청색맹

    처리

    1. 입력 이미지를 읽어 색 정보를 불러오기
    2. 선택한 색각 이상 종류에 맞춰, 해당 사용자에게 이미지가 어떻게 보일지 계산
    3. 원본과 비교하여 구분하기 어려워지는 색 차이를 파악
    4. 구분이 어려운 부분의 색을 해당 사용자가 더 잘 구분할 수 있는 방향으로 조정
    5. 조정한 결과를 새 이미지로 저장

    결과

    보정된 새 이미지 파일(JPG,PNG)을 저장. 원본은 보존한다.

    개발 범위

    • 포함할 기능: 이미지 파일 읽기, 색각 이상 3종류 시뮬레이션, 색 보정 알고리즘 적용, 보정 이미지 저장, 비교 이미지 저장
    • 제외할 기능: 실시간 웹캠 처리, 의료적 진단 기능
    • 한계: 색각 이상 사용자는 특정 색 정보를 인식하지 못하여 원본과 완전히 보이게 만드는 것은 불가능. 실제 색각 이상 사용자에 의한 검증 없이 시뮬레이션 모델에 기반하므로 결과는 개인별로 다르게 느껴질 수 있음.

    사용 예시(Usage example)

    사용자가 (Photos.jpg)를 입력하고 유형으로 녹색맹을 선택. 프로그램은 사진을 시뮬레이션 해 구분이 어려워지는 빨강/초록 영역을 찾고, 그 차이를 파랑/노랑 계열로 옮겨 보정한 (photos_corrected.jpg)를 새로 저장.
